01 — The Brief

A small Manila workshop

The ask: a premium e-commerce site that felt like a boutique, not a template. Built fast. Built to sell.

02 — The Challenge

Everything a real store needs,
nothing it doesn't

The client's market is the Philippines — which means COD, GCash, and Maya aren't optional extras, they're the primary payment expectation. The UI had to handle that reality while still feeling elevated enough to justify a premium price point alongside a ₱99 veil.

01

No framework, full functionality

The project was built entirely in vanilla HTML, CSS, and JavaScript. No React, no Shopify, no template engine. Every interaction — cart, filters, search, hover states — written from scratch, which means it loads fast and has no dependency overhead.

02

22 products across 5 categories

Veils, scarves, accessories, dolls, and lifestyle goods — each with different price points, badge states, and colour variants. The catalogue needed to be browsable without a backend or database powering it.

03

Premium aesthetic on a tight timeline

The brand identity — editorial, warm, handcrafted luxury — had to come through in the design without the luxury of weeks of iteration. Every typographic and layout decision had to be right the first time.

04

Philippine market requirements

COD, GCash, Maya, and BancNet are not afterthoughts in the PH market — they're expected. The checkout and shipping sections had to address these clearly, alongside free-shipping threshold logic and a returns promise that built buyer confidence.

03 — The Hard Part

Building the filter system
without a framework

The product filter was the most technically demanding piece. With five categories plus an "All" view, the system needed to reflow 22 product cards gracefully on click — without a virtual DOM, without React state, and without the grid jumping or flashing during transition.

The solution: each product card carries a data-category attribute. On filter click, the script reads those attributes, toggles a .hidden class, and uses a CSS transition on opacity and transform so the grid fades cards out before the layout reflows. The active filter state persists across the URL via a query parameter — meaning a direct link to /shop?cat=Veils lands with the correct filter already applied, no JavaScript redirect required.

Technical decision

Persisting filter state in the URL (?cat=Veils) instead of JavaScript state was a deliberate choice. It means every filtered view is a shareable, bookmarkable link — useful for a brand that sells through WhatsApp and Instagram DMs, where a client might ask "can you send me the veil link?"
